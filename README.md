# Лабораторная работа № 3. Каталог транспортных маршрутов

Консольное приложение для ведения каталога транспортных маршрутов. Маршрут содержит ID, название, категорию, дату добавления, начальную и конечную точки. Приложение сохраняет каталог в JSON, а список маршрутов и результаты поиска выводит таблицей.

## Команды

| Команда | Что делает |
| --- | --- |
| `add NAME CATEGORY DATE START END [ID]` | Добавляет маршрут. ID можно указать последним аргументом |
| `get ID` | Показывает маршрут по ID |
| `remove ID` | Удаляет маршрут по ID |
| `find-by-category CATEGORY` | Выводит маршруты выбранной категории |
| `find-by-name QUERY` | Ищет по полному названию или его части без учёта регистра |
| `len` | Показывает количество маршрутов |
| `iter` | Выводит все маршруты в порядке строковых ID |
| `contains ID` | Проверяет, есть ли маршрут с таким ID |

### Пример

```bash
python -m transport_routes add "Северный экспресс" "Автобус" 12.11.2025 "Вокзал" "Парк" 101
python -m transport_routes get 101
python -m transport_routes find-by-name "СЕВЕРНЫЙ"
python -m transport_routes find-by-category "Автобус"
python -m transport_routes iter
```

Дата указывается в формате `ДД.ММ.ГГГГ`, `ДД-ММ-ГГГГ` или `ДД/ММ/ГГГГ`. Если пропустить ID, каталог сгенерирует свободный идентификатор в формате `номер-буква`, например `0-А` для автобуса в пустом каталоге.

## Хранение данных

Приложение читает и сохраняет `database.json` в текущей рабочей папке. В корне JSON находятся поле `format_version` и словарь маршрутов `all_element`. При ошибке загрузки исходный каталог в памяти сохраняется.

## Тесты

```bash
PYTHONPATH=src python -m pytest -q
```

Тесты проверяют валидацию маршрутов, операции каталога, автоматическую генерацию ID, порядок итерации, вывод таблиц и работу с JSON.

## Структура проекта

- `src/transport_routes/models.py` — модель маршрута и каталог
- `src/transport_routes/errors.py` — исключения каталога
- `src/transport_routes/handler.py` — загрузка, сохранение и вывод данных
- `src/transport_routes/__main__.py` — команды терминала
- `tests/test_transport_routes.py` — тесты
